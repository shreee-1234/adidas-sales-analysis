# Adidas Sales Analysis

## 📌 Project Overview
This project analyzes Adidas sales data using Python to identify sales trends, top-performing products, regional performance, and retailer insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed
- Sales by Region
- Sales by Product
- Monthly Sales Trend
- Profit Analysis
- Retailer Performance
- Data Visualization

## 📂 Dataset
- adidas_sales.csv

## 📁 Project Structure

adidas-sales-analysis/
├── adidas_sales.csv
├── analysis.ipynb
├── charts/
└── README.md

## 🚀 How to Run

1. Clone the repository
2. Install required libraries
3. Open `analysis.ipynb`
4. Run all cells
